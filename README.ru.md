# Информатика

Архив учебных лабораторных работ по HTML и CSS 2018 года. Статические страницы с примерами разметки и оформления элементов.

## Возможности

- Форматирование текста, ссылки и изображения.
- Таблицы, фреймы и вспомогательные страницы заданий.
- Просмотр в браузере без установки зависимостей.

## Установка и запуск

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайт будет доступен на [localhost:8000](http://localhost:8000). Сборка, база данных и внешние сервисы не нужны.

## Использование

Выберите лабораторную работу на главной странице. Ссылки "Назад" возвращают к списку; страницы в `lab/` содержат задания и примеры. Изображения в `images/` являются ресурсами учебных страниц.

## Проверки

```bash
python3 -W error scripts/check.py
node --check js/javascript.js
```

Проверяются локальные ссылки и ресурсы, включая CSS и страницы фреймов, а также синтаксис JavaScript. Внешние запросы не выполняются.

## Ограничения

Третья лабораторная работа, второе и третье задания пятой работы не заполнены. Устаревшие HTML-элементы и учебная вёрстка сохранены; современная адаптивная версия не разрабатывается. Используются системные шрифты; файлы шрифтов без лицензии на распространение не входят в проект.
