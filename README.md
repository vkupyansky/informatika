# Информатика

Архив учебных лабораторных работ по HTML и CSS 2018 года. Статические страницы с форматированием текста, ссылками, таблицами, фреймами и оформлением элементов.

## Просмотр

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайт будет доступен на [localhost:8000](http://localhost:8000). Сборка, база данных и внешние сервисы не нужны.

## Содержимое

- `index.html`: список лабораторных работ.
- `lab/`: задания и вспомогательные страницы.
- `css/`, `js/`, `images/`: оформление и ресурсы.

Учебная разметка сохранена, включая устаревшие HTML-элементы. Третья работа, второе и третье задания пятой работы не заполнены. Сторонний шрифт заменён системным; файлы без лицензии на распространение не включены.

## Проверка

```bash
python3 -W error scripts/check.py
node --check js/javascript.js
```

Проверка ищет отсутствующие локальные ресурсы и ссылки, включая CSS и страницы фреймов. Текущее состояние описано в [STATUS.md](STATUS.md).
