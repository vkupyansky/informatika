# Сопровождение

- Проект представляет собой архив учебных статических страниц. Сохраняйте задания и их исходный смысл.
- `index.html` содержит навигацию, `lab/` задания, `css/` и `js/` оформление.
- Не добавляйте сборщик или серверную часть для просмотра HTML.
- После правок запускайте `python3 -W error scripts/check.py` и `node --check js/javascript.js`.
- Не публикуйте секреты, локальные файлы и сторонние материалы без права распространения.
- Назначение и запуск описаны в README, ограничения в STATUS.
